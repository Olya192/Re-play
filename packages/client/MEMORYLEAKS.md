## Общая информация

### Цель проверки

Выявить утечки объектов в памяти в React-приложении Re-play для оценки стабильности работы приложения при длительном использовании.

### Области проверки

- Игровой цикл (GamePlayPlaceholder)
- Управление модальными окнами (StartModal, ResultsModal, PauseModal, HelpModal)
- Подписки на события (ResizeObserver, event listeners)
- Redux state и middleware
- Навигация между страницами (React Router)

## Методология

Для каждого сценария выполнялись следующие действия:

1. Выполнение тестового сценария
2. Создание Heap Snapshot
3. Принудительный запуск Garbage Collector
4. Повторное создание Heap Snapshot
5. Сравнение снимков памяти и анализ объектов, оставшихся в куче после GC

### Тест 1: Игровой цикл

**Действия:**

1. Открыть игровую страницу (`/`)
2. Нажать «Играем!»
3. Играть до конца раунда
4. Нажать «Поедим ещё!»
5. Повторить 10 раз

**Ожидаемый результат:**

JS Heap не должен демонстрировать устойчивого роста после завершения цикла. Detached Nodes не должны систематически накапливаться.

---

### Тест 2: Модальные окна (PauseModal)

**Действия:**

1. Начать игру
2. Нажать Esc → открывается PauseModal
3. Нажать Esc → закрывается PauseModal
4. Повторить 30 раз

**Ожидаемый результат:**

DOM-узлы модального окна должны удаляться после закрытия. Event listeners должны корректно очищаться.

---

### Тест 3: Навигация между страницами

**Действия:**

1. Открыть `/main`
2. Перейти на `/forum`
3. Вернуться на `/main`
4. Повторить 20 раз

**Ожидаемый результат:**

Компоненты страниц должны полностью размонтироваться и освобождать используемую память.

---

### Тест 4: Защищённые роуты

**Действия:**

1. Открыть `/main`
2. Перейти на `/user-profile`
3. Перейти на `/profile`
4. Вернуться на `/main`
5. Повторить 15 раз

**Ожидаемый результат:**

Защищённые компоненты должны корректно очищаться при размонтировании.

## Наблюдаемые утечки памяти

### Утечка №1: Отсоединённые DOM-узлы (GamePlayPlaceholder)

**Результаты теста:**

- `# Delta`: **+27**
- `Size Delta`: **~500 Б**
- Объекты остаются в Heap Snapshot после вызова GC

**Наблюдение:**

После многократного перезапуска игрового цикла в памяти сохраняются отсоединённые DOM-элементы и связанные с ними внутренние структуры React.

**Возможная причина:**

Требует дополнительной проверки удержание ссылок через коллекцию `itemRefs`.
Возможно, Map `itemRefs` может сохранять ссылки на элементы, которые уже были удалены из DOM, если очистка коллекции выполняется не во всех сценариях жизненного цикла компонента.

**Последствия:**

При текущем объёме тестирования влияние на производительность не выявлено. Обнаружено незначительная утечка памяти (~500 Б за 10 циклов).

---

### Утечка №2: InternalNode при работе PauseModal

**Результаты теста:**

- `# Delta`: **+42**
- `Size Delta`: **+2,5 КБ**
- Объекты остаются в Heap Snapshot после вызова GC

**Наблюдение:**

После многократного открытия и закрытия PauseModal фиксируется накопление объектов типа InternalNode.

**Возможная причина:**

Возможные источники удержания:

- Повторное создание обработчиков событий;
- Внутренние механизмы React;
- Использование Portal в Ant Design;
- Особенности работы React StrictMode в режиме разработки.

**Последствия:**

Обнаруженная утечка памяти не оказывает заметного влияния на работу приложения.

---

### Утечка №3: InternalNode при навигации

**Результаты теста:**

- `# Delta`: **+12**
- `Size Delta`: **+704 Б**
- Объекты остаются в Heap Snapshot после вызова GC

**Наблюдение:**

После серии переходов между страницами фиксируется небольшое накопление внутренних объектов React.

**Возможная причина:**

Возможными факторами являются:

- Внутренняя работа React Router;
- Особенности development-сборки;
- Кэширование данных библиотеками состояния или запросов.

**Последствия:**

Рост памяти незначителен и не свидетельствует о наличии критической утечки памяти.

## Утечки без существенных отклонений

### Защищённые роуты (Профиль)

**Результаты теста:**

- `# Delta`: **+1**
- `Size Delta`: **+56 Б**
- Объекты остаются в Heap Snapshot после вызова GC

**Наблюдение:**

Зафиксирован единичный InternalNode без признаков систематического накопления объектов.

**Вывод:**

Полученные значения находятся в пределах статистической погрешности и не свидетельствуют о наличии утечки памяти.
