# 03. Состояние игры

## Общая схема

Игровое состояние разделено на два Redux slice:

- `gameSession` - хранит фактические данные и логику текущего раунда
- `gameUi` - управляет состоянием интерфейса

## gameSession

### Основные поля

- `levelId` - текущий уровень
- `elapsedMs` - прошедшее время раунда
- `score` - текущий счет
- `caughtCount` - сколько объектов поймал игрок
- `missedCount` - сколько объектов было пропущено
- `eatenCount` - сколько объектов съел монстр
- `monsterLength` - текущий размер/длина монстра
- `phase` - текущая фаза игры
- `inventory` - инвентарь
- `updatedAt` - техническая метка обновления

## Фазы игры

Сейчас поддерживаются четыре фазы:

- `intro` - стартовый экран
- `playing` - активный раунд
- `paused` - игра приостановлена
- `ended` - раунд завершён

### Текущее фактическое поведение

Хотя фаза `intro` уже существует в модели, старт игры сейчас происходит сразу.

Это связано с тем, что:

- В `initialGameSessionState.phase` временно выставлено `playing`
- Полноценное стартовое модальное окно ещё не подключено
- В `persistGameSession.ts` при восстановлении из `localStorage` фаза принудительно переводится в `playing`

## Основные действия `gameSession`

### `setPhase`

Меняет фазу игры.

### `setLevel`

Переключает уровень и сбрасывает основные счетчики раунда.

### `syncFromEngine`

Синхронизирует данные, которые приходят из временного игрового движка:

- `elapsedMs`
- `score`
- `caughtCount`
- `missedCount`
- `monsterLength`
- `inventory`

### `incrementCaught`

Увеличивает: `caughtCount`, `score`

### `incrementMissed`

Увеличивает: `missedCount`

### `incrementEaten`

Увеличивает: `eatenCount`

## `gameUi`

`gameUi` хранит, какое модальное окно сейчас открыто

Поддерживаемые значения:

- `start`
- `pause`
- `results`
- `help`
- `null`

## Persistence

Сессия сохраняется в `localStorage` по ключу:

- `replay:gameSession`

Сохраняется весь `gameSession`

Это позволяет восстанавливать состояние после перезагрузки страницы, но сейчас используется временный обходной сценарий с форсированным `phase: 'playing'`.
