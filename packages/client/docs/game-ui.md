# 04. UI

## Общая модель

Игра движется к модели одного основного экрана, поверх которого открываются слои интерфейса и модальные окна.

Главный экран:

- `GameRoot`

## Слои экрана

Внутри `GameRoot` сейчас собираются следующие части:

- `GameLayout`
- `GameStage`
- `RotatingBackground`
- `BiomeBackground`
- `GameCanvas`
- `GamePlayPlaceholder`
- `GameHeader`
- `GameFooter`

## Верхняя панель

`GameHeader` показывает:

- Текущего пользователя
- Планету
- Биом

## Нижняя панель

`GameFooter` содержит:

- Кнопку помощи
- Ссылку на форум
- Ссылку на лидерборд

Кнопка помощи открывает:

- Модальное окно `help`

## Экран результата

Компонент `GameOverModal` уже подготовлен и умеет показывать:

- Текущий счет
- Лучший счет
- Действие повтора
- Возврат в меню
