# 02. Игровой Цикл

## Основа цикла

Главный цикл игры сейчас реализован в `GamePlayPlaceholder` через `requestAnimationFrame`

Параллельно с кадровым циклом работает отдельный таймер спавна новых объектов.

## Последовательность на каждом кадре

На каждом кадре происходит:

1. Вычисление дельты времени `dt`.
2. Обновление длительности текущего раунда.
3. Проверка, не закончилось ли время уровня.
4. Пересчет позиции каждого падающего объекта.
5. Проверка, был ли объект съеден монстром.
6. Проверка, был ли объект пропущен.
7. Удаление обработанных объектов.
8. Перемещение монстра к ближайшей цели.

## Спавн объектов

Объекты появляются случайно с интервалом:

- от `2000 ms` до `3000 ms`

При спавне задаются:

- `id`
- `kind`
- Позиция по `x`
- Время появления `spawnedAt`

## Падение объектов

Позиция по `y` считается из времени жизни объекта относительно `spawnedAt`.

Полное время падения одного объекта:

- `4500 ms`

## Ловля игроком

Если игрок нажимает на объект:

- Объект удаляется с экрана
- Увеличивается `caughtCount`
- Увеличивается `score`

Текущая формула счета за пойманный объект:

- `+1 score`

## Съедание монстром

Если объект пересекает зону рта монстра:

- Объект удаляется
- Увеличивается `eatenCount`

Сейчас это не меняет `score`, но в коде предусмотрено дальнейшее расширение этой логики.

## Пропуск объекта

Если объект уходит ниже нижней границы экрана:

- Объект считается пропущенным
- Увеличивается `missedCount`

Сейчас это тоже не меняет `score`.

## Завершение раунда

Раунд заканчивается, когда:

- `elapsedMs >= durationMs`

После этого:

- Финальное время синхронизируется в store
- `phase` меняется на `ended`
- Открывается результат
