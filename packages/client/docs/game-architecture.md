## Уровни и биомы

Метаданные уровня описывают:

- Название планеты
- Название биома
- Длительность уровня
- Акцентные цвета
- Фоновые изображения

Сейчас в коде используется один уровень:

- `earth/forest`

Текущая длительность раунда:

- `33_000 ms`

## Временный движок

`GamePlayPlaceholder` по сути является рабочим временным runtime-слоем:

- Управляет спавном
- Считает движение объектов
- Двигает монстра
- Обновляет store
- Завершает раунд

Название `placeholder` важно: это уже функционирующий MVP, но еще не финальная архитектура движка.

## Что уже работает

В проекте уже реализованы:

- Единый игровой экран
- Уровневые метаданные
- Таймер раунда
- Спавн и падение объектов
- Ловля объектов игроком
- Автоматическое движение монстра
- Учет пойманных, пропущенных и съеденных объектов
- Завершение уровня по времени
- Сохранение сессии в `localStorage`

## Что еще не завершено

В коде явно видны следующие незавершенные зоны:

- Полноценная стартовая фаза `intro`
- Полная система модальных окон `start / pause / results / help`
- Финальная scoring-система
- Последствия съедания предметов монстром
- Настоящая контентная модель предметов
- Полноценный Сanvas вместо временной DOM-реализации
