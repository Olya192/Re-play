# 01. Общая Концепция

## Идея игры

Текущая версия игры-кликера `Re-play` представляет собой одиночный раунд на одном игровом экране.

Основной сценарий такой:

- На экране сверху появляются падающие объекты
- Игрок должен успеть перехватить их до того, как они будут съедены монстром или упадут вниз
- Монстр автоматически перемещается по горизонтали к ближайшей цели
- По окончании светового дня игра завершается

## Главные сущности

### Игрок

Игрок взаимодействует с объектами напрямую:

- Каждый объект рендерится как интерактивный элемент
- На `pointer down` объект считается пойманным

### Падающие объекты

Сейчас в коде используются два временных типа:

- `circle` - круг
- `square` - квадрат

Это не финальные игровые ассеты, а заглушки для отработки механики.

### Монстр

Монстр расположен внизу экрана и автоматически двигается по оси `x`

Он:

- Ищет ближайший объект и приближается к нему
- Съедает объект при пересечении с зоной рта

### Уровень

Уровень сейчас задается через биомные метаданные.

На данный момент в коде есть один дефолтный уровень:

- `earth/forest`

## Цель раунда

Прямо сейчас цель раунда выражена не через условие победы или поражения, а через максимально результативное прохождение до конца дня

Игрок может:

- Ловить предметы сам
- Следить за тем, сколько предметов съедает монстр
- Минимизировать количество пропусков

## Текущий характер реализации

Текущая игра уже ведет себя как рабочий MVP, но ядро механики пока реализовано временным способом:

- Логика работает через DOM + `requestAnimationFrame`
- `canvas` подготовлен, но не является источником геймплея
